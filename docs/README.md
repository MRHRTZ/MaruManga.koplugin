# MaruManga Downloader Development

This directory documents the KOReader plugin implementation and contributor workflow.

- [Structure and UI](STRUCTURE.md)
- [Repositories and sources](SOURCES.md)
- [Testing and Android deployment](TESTING_AND_ADB.md)

The plugin is a local Lua application. Repositories publish validated JSON only; adapters are trusted Lua shipped with the plugin. APK or website research must be read-only. Do not execute downloaded APKs, Lua, JavaScript, or source-provided code.
